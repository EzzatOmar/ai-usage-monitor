# B1 - fix release actor isolation build
[Overview](../BASED.md)

Restore the GitHub release build by making the Settings view's main-actor
ownership explicit across supported Swift toolchains.

## Context

The 0.1.18 release workflow run `32142614236` failed on macOS 14 while compiling
`SettingsRootView.swift`. Its compiler does not infer main-actor isolation for
helper methods and computed properties on SwiftUI views, so they could not
access the `@MainActor MenuBarViewModel`. Local debug/release builds on the
newer installed toolchain inferred the isolation and passed.

## Scope

- Add explicit main-actor isolation to settings views that own or access `MenuBarViewModel`.
- Re-run local verification and the failed deployment path.

## Non-goals

- Change Settings behavior or layout.
- Change CI runner/toolchain versions.

## Acceptance Criteria

- [ ] Settings helpers compile without actor-isolation diagnostics on the release runner.
- [x] Full tests and local release packaging continue to pass.
- [ ] GitHub publishes release 0.1.18 successfully.

## Plan

1. Annotate the model-owning Settings view boundaries with `@MainActor`.
2. Run tests, release build, package checks, and BASED validation.
3. Push the fix and verify the GitHub release and public artifact.
