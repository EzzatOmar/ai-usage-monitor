# A1 - add manual update check action
[Overview](../BASED.md)

Add a footer action that lets users immediately check GitHub releases for a
new app version without waiting for the periodic updater.

## Context

`UpdateChecker` already performs startup and four-hour periodic checks through
`checkForUpdate()`, while `MenuBarRootView` currently places only the GitHub
link and Quit button in its bottom row. The requested control belongs between
those actions and must disappear once `UpdateStatus.available` is published.

## Scope

- Add a manual update-check action to `MenuBarViewModel` and the footer in
  `Sources/MenuBarView.swift`.
- Keep the control hidden when an update is available or being downloaded.
- Add focused automated coverage for the visibility decision.

## Non-goals

- Change the GitHub release API, periodic check interval, download, install, or
  restart behavior.
- Redesign the rest of the menu or usage refresh controls.

## Acceptance Criteria

- [x] A `Check Updates` button is displayed between `Star on GitHub` and `Quit`
  when no update is available.
- [x] Activating `Check Updates` starts a fresh update check immediately.
- [x] The button is absent while an update is available or downloading.
- [x] Existing update download/install UI and behavior remain intact.

## Plan

1. Expose the footer visibility decision and a manual-check action through the
   observable view model.
2. Insert the button in the existing footer row and bind it to the action.
3. Cover the status-to-visibility rule with unit tests, then run project and
   BASED validation.
